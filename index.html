Linear A

อักษรมิโนอันแห่งยุคสำริด

เว็บให้ความรู้ทั่วไปเกี่ยวกับระบบการเขียนของอารยธรรมมิโนอัน อ้างอิงจากแหล่งข้อมูลวิชาการ เช่น Oxford Classical Dictionary และ Unicode Consortium

01 — บทนำ

Linear A คืออะไร?

Linear A (อักษรลิเนียร์ เอ) เป็นระบบการเขียนที่ใช้ในยุคสำริด บนเกาะครีตและพื้นที่รอบทะเลอีเจียน ราว 1800–1450 ปีก่อนคริสตกาล ใช้โดยชาวมิโนอัน อารยธรรมสำคัญของภูมิภาคนี้

จุดสำคัญที่ควรรู้ก่อน

นักวิชาการสามารถอ่านรูปร่างของสัญลักษณ์ Linear A ได้บางส่วนแล้ว แต่ยังไม่สามารถระบุความหมายของภาษามิโนอันที่อยู่เบื้องหลังได้อย่างแน่ชัด

ดังนั้น Linear A จึงยังถือว่า "ยังไม่ถูกถอดรหัส" (undeciphered) ในวงการวิชาการปัจจุบัน — เป็นหนึ่งในปริศนาทางภาษาศาสตร์ที่เก่าแก่และคงค้างมาที่สุดของโลก

สิ่งที่ทำให้ Linear A น่าสนใจเป็นพิเศษคือ อักษรรุ่นหลังอย่าง Linear B ซึ่งมีรูปร่างคล้ายกันมาก กลับถูกถอดรหัสได้สำเร็จแล้วตั้งแต่ศตวรรษที่ 20 แต่ Linear A ที่มาก่อนกลับยังคงเป็นปริศนาอยู่จนถึงทุกวันนี้

02 — โครงสร้างอักษร

Linear A หน้าตาเป็นอย่างไร?

Linear A ไม่ใช่ตัวอักษรแบบ A–Z ที่แต่ละตัวแทนเสียงเดี่ยว ๆ แต่จัดอยู่ในกลุ่ม "โลโก-พยางค์" (logo-syllabary) ซึ่งผสมสัญลักษณ์สามประเภทเข้าด้วยกัน

  • Syllabograms — สัญลักษณ์ที่แทนเสียงพยางค์
  • Logograms / Ideograms — สัญลักษณ์ที่แทนสิ่งของหรือแนวคิดโดยตรง
  • ตัวเลขและเศษส่วน — ใช้ในงานบันทึกบัญชี

นักวิชาการสามารถเสนอค่าทางเสียงของสัญลักษณ์บางตัวได้ โดยอาศัยการเปรียบเทียบกับ Linear B ซึ่งถอดรหัสสำเร็จแล้ว แต่ต้องเข้าใจให้ชัดว่า การรู้ค่าเสียงของสัญลักษณ์ ไม่เท่ากับการรู้ความหมายของคำหรือภาษา Linear A

03 — เปรียบเทียบ

Linear A เกี่ยวข้องกับ Linear B อย่างไร?

Linear B ถูกพัฒนาขึ้นภายหลัง และมีรูปร่างสัญลักษณ์จำนวนมากคล้ายกับ Linear A แต่ทั้งสองระบบมีความแตกต่างสำคัญที่ทำให้แปลข้ามกันตรง ๆ ไม่ได้

Linear B ถูกถอดรหัสได้สำเร็จในศตวรรษที่ 20 และพบว่าภาษาที่บันทึกไว้คือภาษากรีกยุคไมซีเนียน แต่ปัญหาคือเราไม่สามารถนำค่าของ Linear B มาแปล Linear A ได้ตรง ๆ แม้สัญลักษณ์จะคล้ายกัน เพราะภาษาที่อยู่เบื้องหลังอักษรทั้งสองระบบอาจแตกต่างกันโดยสิ้นเชิง

04 — การใช้งาน

Linear A ถูกใช้ทำอะไร?

หลักฐานที่พบส่วนใหญ่เกี่ยวข้องกับการบริหารและกิจกรรมทางศาสนา ไม่ใช่งานวรรณกรรมหรือประวัติศาสตร์

  • บันทึกสินค้าและจำนวนสิ่งของ
  • การเก็บและแจกจ่ายทรัพยากร
  • ชื่อบุคคลและชื่อสถานที่
  • สิ่งของที่เกี่ยวข้องกับพิธีกรรม

จารึกที่พบปรากฏอยู่บนภาชนะ แผ่นดินเหนียว รวมถึงวัตถุโลหะและหิน โดย Oxford Classical Dictionary ระบุว่าหลักฐานส่วนใหญ่เป็นข้อความสั้น ๆ ที่มีรูปแบบค่อนข้างซ้ำกัน

ปัจจุบันยังไม่มีหลักฐานชัดเจนว่า Linear A เคยถูกใช้บันทึกงานประเภทมหากาพย์ ประวัติศาสตร์ หรือจดหมายทางการทูต แบบที่พบในอารยธรรมโบราณอื่น ๆ

05 — หัวใจของปัญหา

ทำไมถึงถอดรหัสไม่ได้?

การถอดรหัส Linear A ติดปัญหาใหญ่อยู่สามข้อ ซึ่งแต่ละข้อเสริมกันจนทำให้งานนี้ยากขึ้นไปอีก

ปัญหาที่ 1 — ไม่มี "Rosetta Stone"

ในกรณีของอียิปต์โบราณ เรามี Rosetta Stone ที่มีข้อความเดียวกันเขียนไว้หลายภาษา ทำให้จับคู่ความหมายกันได้ แต่ Linear A ยังไม่มีข้อความสองภาษาแบบนี้ที่จะใช้เป็นกุญแจไขรหัส

ปัญหาที่ 2 — ข้อความที่เหลืออยู่สั้นเกินไป

ตัวอย่างจำนวนมากเป็นข้อความบัญชีสั้น ๆ ในรูปแบบ สัญลักษณ์ → จำนวน → สิ่งของ ทำให้มีข้อมูลด้านไวยากรณ์น้อยมาก Oxford ระบุว่าจำนวนข้อความที่หลงเหลือ สภาพที่เสียหาย และความสั้นของข้อความ เป็นอุปสรรคสำคัญต่อการทำความเข้าใจภาษา

ปัญหาที่ 3 — ไม่รู้ว่าภาษามิโนอันเป็นภาษาอะไร

นี่อาจเป็นปัญหาใหญ่ที่สุด เรามั่นใจค่อนข้างมากว่า Linear A ใช้บันทึกภาษามิโนอัน แต่ยังไม่สามารถจัดภาษานี้เข้ากับตระกูลภาษาใดได้อย่างเป็นที่ยอมรับทั่วไป มีสมมติฐานหลายแบบที่ถูกเสนอ ได้แก่

  • ภาษาที่เกี่ยวข้องกับกลุ่มภาษาในอนาโตเลีย
  • ภาษาในกลุ่มใกล้เคียงกับ Hurrian
  • ภาษาตระกูล Indo-European
  • ภาษาที่สูญหายไปแล้วโดยไม่มีทายาททางภาษา
  • หรือภาษาที่ไม่อาจจัดเข้าตระกูลภาษาใดที่รู้จักในปัจจุบัน

แต่จนถึงตอนนี้ยังไม่มีข้อสรุปใดที่วงการวิชาการยอมรับโดยทั่วไป

06 — สถานะปัจจุบัน

แล้วนักวิชาการ "อ่าน" Linear A ได้ไหม?

คำตอบคือได้บางส่วน แต่ต้องแยกคำว่า "อ่าน" กับ "แปล" ออกจากกันให้ชัดเจน

นักวิชาการสามารถทำ transliteration หรือถอดสัญลักษณ์ออกมาเป็นชุดอักษรละตินตามค่าเสียงที่สันนิษฐานไว้ได้ เช่น สัญลักษณ์ชุดหนึ่งอาจถอดเสียงออกมาได้เป็น a-ka-u-ta

แต่นั่นไม่ได้แปลว่าเรารู้ว่า a-ka-u-ta หมายความว่าอะไร เพราะเรายังไม่รู้จักภาษามิโนอันมากพอที่จะแปลความหมายได้

สถานะโดยสรุปคือ: รู้รูปสัญลักษณ์ → รู้ค่าเสียงบางตัว → อ่านออกเสียงได้โดยประมาณ → แต่ยังไม่รู้ความหมายทั้งหมด

ความแตกต่างระหว่างการ "อ่านออกเสียง" กับการ "เข้าใจความหมาย" นี้เป็นจุดที่มักถูกเข้าใจผิดมากที่สุดเวลาพูดถึง Linear A

07 — ข้อควรระวัง

มีคนอ้างว่าถอดรหัส Linear A ได้แล้วหรือยัง?

ควรอ่านอย่างระมัดระวัง

มีนักวิจัยและผู้เขียนบางรายเสนอว่าตนเองสามารถถอดรหัส Linear A ได้แล้ว เช่น แนวทางที่เชื่อมโยงภาษามิโนอันเข้ากับกลุ่มภาษา Hurrian

แต่การมีงานที่ "อ้างว่าถอดรหัสได้แล้ว" ไม่ได้แปลว่าปัญหาถูกแก้ไขแล้วในระดับที่วงการวิชาการยอมรับ ตัวอย่างเช่น Oxford Classical Dictionary ซึ่งเป็นแหล่งอ้างอิงวิชาการ ยังคงจัด Linear A ไว้ในสถานะ undeciphered อยู่

หากต้องการเขียนถึงเรื่องนี้อย่างถูกต้อง ควรใช้ประโยคว่า "Linear A ยังไม่ได้รับการถอดรหัสอย่างเป็นที่ยอมรับในวงการวิชาการ" ซึ่งแม่นยำกว่าการพูดว่า "ไม่มีใครอ่าน Linear A ได้เลย"

08 — ที่มาของอักษร

Linear A กับ Cretan Hieroglyphic

ก่อนจะมี Linear A เกาะครีตเคยมีระบบการเขียนอีกแบบหนึ่งมาก่อน เรียกว่า Cretan Hieroglyphic หรืออักษรเฮียโรกลิฟิกแห่งครีต

Cretan Hieroglyphic → Linear A → Linear B

ลำดับนี้เป็นภาพคร่าว ๆ เท่านั้น ความสัมพันธ์ทางประวัติศาสตร์และการพัฒนาที่แท้จริงระหว่างระบบการเขียนทั้งสามยังเป็นหัวข้อที่นักวิชาการศึกษาอยู่ ไม่ควรตีความว่าเป็นการวิวัฒนาการแบบเส้นตรงง่าย ๆ

09 — ในโลกดิจิทัล

Linear A มีอยู่ใน Unicode ไหม?

มี — ตั้งแต่ Unicode รุ่นใหม่ ๆ ได้กำหนดช่วงรหัสสำหรับ Linear A ไว้โดยเฉพาะ ที่ตำแหน่ง U+10600 ถึง U+1077F

Unicode ระบุว่า Linear A ถูกใช้งานในช่วงราว 1700–1450 ปีก่อนคริสตกาล และมีการเข้ารหัสสัญลักษณ์ตามระบบจัดหมวดหมู่ที่นักวิชาการใช้ เช่นระบบ GORILA

ที่น่าสนใจคือ ในทางคอมพิวเตอร์เราสามารถพิมพ์อักษร Linear A ได้จริงแล้วในปัจจุบัน แม้ว่าภาษาที่อักษรนี้ใช้บันทึกจะยังไม่ถูกถอดความอย่างสมบูรณ์ก็ตาม

10 — สรุปแบบสั้น

สรุป: Linear A คือปริศนาที่ยังรอคำตอบ

Linear A คือระบบอักษรของอารยธรรมมิโนอัน ใช้งานในช่วง 1800–1450 ปีก่อนคริสตกาล บนเกาะครีต

มิโนอัน ครีต → Linear A → บันทึกสินค้า / บริหาร / ศาสนา

ภาษาที่ถูกบันทึกไว้ในอักษรนี้คือภาษามิโนอัน ซึ่งจนถึงวันนี้ยังไม่มีใครทราบแน่ชัดว่าสัมพันธ์กับตระกูลภาษาใด ทำให้ Linear A ยังคงสถานะ "ยังไม่ถูกถอดรหัส" อย่างเป็นทางการในวงการวิชาการ

สิ่งที่ทำให้เรื่องนี้น่าสนใจเป็นพิเศษคือ Linear B ซึ่งมีรูปร่างตัวอักษรคล้ายกันและเกิดขึ้นภายหลัง กลับถูกถอดรหัสสำเร็จไปแล้วตั้งแต่ศตวรรษที่ 20 ขณะที่ Linear A ผู้เป็นต้นทางกลับยังคงเป็นปริศนาที่รอคำตอบอยู่จนถึงทุกวันนี้
